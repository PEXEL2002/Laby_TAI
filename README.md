# Materiały i Zadania Laboratoryjne – TAI (INF.03)

Prowadzący: Bartłomiej Kuk

Repozytorium zawiera arkusze zadań laboratoryjnych przygotowujących do części praktycznej egzaminu zawodowego **INF.03** (Technik Informatyk). Pliki PDF z kolejnymi zadaniami są publikowane dzień przed planowanymi zajęciami.

---

## 🛠️ Podstawowe zasady i zaliczenie zajęć

1. **Praca sekwencyjna:** Zadania w arkuszach należy wykonywać kolejno (ocena 2 ➔ 3 ➔ 4 ➔ 5). Przejście do wyższego poziomu wymaga pełnej realizacji poleceń z poziomów niższych.
2. **Odbiór wyłącznie na zajęciach:** Wszelkie pytania, sprawdzanie oraz oficjalny odbiór kodu odbywają się wyłącznie podczas trwania zajęć laboratoryjnych.
3. **Weryfikacja wiedzy (Obrona ustna):** Obowiązuje **bezwzględny zakaz korzystania ze sztucznej inteligencji (AI)**. Warunkiem koniecznym do wpisania oceny jest pomyślne przejście krótkiej obrony ustnej (pytania z działania kodu i pojęć technicznych).
4. **Dokumentacja:** Zalecane źródła wiedzy to oficjalna dokumentacja:
   - [MDN Web Docs](https://developer.mozilla.org/)
   - [W3Schools](https://www.w3schools.com/)
